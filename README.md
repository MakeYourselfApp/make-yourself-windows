# Make Yourself for Windows

Downloads for the Windows app. The source code is not here.

[![Watch the 35-second film](https://img.youtube.com/vi/6G2QG8oSBH8/hqdefault.jpg)](https://www.youtube.com/watch?v=6G2QG8oSBH8)

**[Watch the 35-second film](https://www.youtube.com/watch?v=6G2QG8oSBH8)** · [makeyourself.app](https://makeyourself.app)

**[Download the latest version](https://github.com/MakeYourselfApp/make-yourself-windows/releases/latest)** — run `MakeYourself-Setup-<version>.exe`.

The installer is not code-signed yet, so Windows may show "Windows protected your PC". Click **More info → Run anyway**.

The app updates itself. Pro is bought in the Make Yourself phone app on Google Play; sign in on the laptop with the same Google account and it unlocks.
